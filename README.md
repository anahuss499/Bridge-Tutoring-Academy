# Bridge Tutoring Academy website

Static website (HTML, CSS, JS). No build step.

## Structure
- `index.html` - the page
- `css/styles.css` - all styles (colour tokens at the top, in `:root`)
- `js/main.js` - mobile menu
- `assets/logo.jpg`, `emblem.jpg` - logo (full and header crop)
- `assets/promo.mp4`, `promo-poster.jpg` - promo video and its thumbnail
- `assets/favicon.png`, `icon-192.png` - site icons

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
Upload the folder to any static host (Netlify, GitHub Pages, Cloudflare Pages, Vercel).

## Edit
- Colours: change the variables in `:root` in `css/styles.css`.
- Form link: search `docs.google.com/forms` in `index.html`.
